# 職務経歴書

- Vite + React + TypeScript で職務経歴書を表示します。
- ボタン、レイアウト、表には React Bootstrap を使用します。
- 余白、文字サイズ、罫線は Bootstrap のクラスで指定します。
- `src/print.css` には用紙設定と改ページ制御のみを記載します。
- 表示コンポーネントは `src/components/` に配置します。
- `data/` 以下の JSON を編集して内容を更新します。
- PDF はブラウザの印刷機能で保存します。

## 起動

```sh
npm install
npm run dev
```

## データの編集

- `data/profile.json` に更新日、氏名、自己PRを記載します。
- `data/experience/*.json` に本業の職歴を記載します。
- `data/side-experience/*.json` にフリーランス・副業の職歴を記載します。
- 職歴ファイルは自動で読み込まれます。
- ファイル名の番号と `order` は、各ディレクトリ内で古い職歴から順に振ります。
- 本業の「職務経歴」の後に「フリーランス・副業」をまとめて表示します。
- 各区分内は `order` の降順で、新しい職歴から表示します。
- 表示区分は保存先ディレクトリで判断します。
- 新しい職歴は保存先ディレクトリの最大番号の次を使って追加します。
- 既存の番号には欠番がありますが、詰め直す必要はありません。
- 例えば、現在の最大番号が `07` なら `08-company.json` を追加します。
- 追加するファイルの `order` は `8` にします。
- 同じ `order` の場合はファイル名順で表示します。
- 自己PRの `self_introduction` は段落ごとの文字列配列で記載します。
- `description` も段落ごとの文字列配列で記載します。
- 配列の各要素は独立した段落として表示されます。
- `positions` と `technologies` は項目ごとの配列で記載します。
- `period` の `\n` は担当期間の改行に使えます。
- 日付は自由記述です。
- 更新日は自動更新せず、`as_of` の値を表示します。

### 会社ごとの職歴

```json
{
  "order": 1,
  "name": "株式会社サンプル",
  "url": "https://example.com/",
  "period": "2025年2月～現在",
  "page_break_before": false,
  "roles": [
    {
      "period": "2025年2月〜\n現在",
      "positions": ["エンジニア"],
      "description": ["サービスの開発を担当。"],
      "technologies": ["TypeScript / React", "AWS / Terraform"]
    }
  ]
}
```

- `page_break_before` は省略可能です。
- `true` にすると、印刷時にその会社の前で改ページします。
- 使用技術の記載がない場合は `technologies` を空配列にします。
- 型定義は `src/types.ts` にあります。
- 元の Word の文章を初期データに移しています。
- 元の表記や日付の誤記は自動修正していません。

## PDF 保存

1. 画面上部の「印刷 / PDF 保存」を押します。
2. 送信先を「PDF に保存」にします。
3. 用紙を A4 縦にします。
4. 倍率を 100% にします。
5. 余白は既定の設定を使います。
6. ブラウザのヘッダーとフッターをオフにします。
7. プレビューを確認して保存します。

- 印刷時には操作ボタンが非表示になります。
- 表の列見出しは会社ごとの先頭にだけ表示します。
- 長い職歴は本文の段落間で改ページします。
- 期間欄はセル結合を使わず、先頭の行だけに表示します。
- 1 ページを超える段落はブラウザによって分割されます。
- 会社名と列見出しだけがページ末尾に残らないように指定しています。
- フォントとブラウザによって改ページ位置が変わることがあります。
- 画面表示は連続した文書です。
- 実際のページ区切りは印刷プレビューで確認します。

## 検証

```sh
npm run lint
npm run build
```

- lint は Biome で実行します。
- 既存の React Hooks とコンポーネントのエクスポートに関するルールを設定しています。
- Biome の推奨ルール一式は有効にしていません。
- `npm run format` でソースコードと設定ファイルを整形します。
- 個人データとロックファイルは Biome の処理対象から除外しています。

- 自動テストの実行基盤は未導入です。
- ビルド成果物は `dist/` に出力します。
- JSON 内の情報はビルド成果物にも含まれます。
